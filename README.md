# ARONA — GitHub Pages Edition

سایت رسمی آرونا، نسخه ایستا برای انتشار در GitHub Pages.

## انتشار
1. در GitHub یک مخزن جدید بسازید (مثلاً `arona-website`).
2. همه فایل‌های **داخل همین پوشه** را در شاخه `main` و ریشه مخزن آپلود کنید (نه خود فایل ZIP).
3. Settings → Pages → Build and deployment → Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save.
4. آدرس سایت پس از انتشار به شکل `https://USERNAME.github.io/arona-website/` خواهد بود.
5. برای دامنه شخصی از Settings → Pages → Custom domain استفاده کنید و DNS را مطابق راهنمای GitHub تنظیم کنید.

## ویرایش محتوا
- متن‌ها، پروژه‌ها، افتخارات و گالری: `content.json`
- عکس یا ویدیوی جدید: فایل را در `assets/media/` بگذارید، سپس یک آیتم `media` به `items` در `content.json` اضافه کنید. مقدار `file` فقط نام فایل باشد؛ `category` می‌تواند `events`، `projects` یا `videos` باشد.
- طراحی: `style.css`، انیمیشن‌ها: `motion.js`.
- برای تغییرات، Commit کنید؛ GitHub Pages سایت را دوباره منتشر می‌کند.

## نکات مهم
- این نسخه **پنل مدیریت، ورود مدیر، API و پایگاه داده ندارد**؛ GitHub Pages فقط فایل‌های ایستا را میزبانی می‌کند.
- آمار بازدید نیازمند سرویس تحلیل بازدید جداگانه است.
- عکس‌ها و ویدیوهای داخل مخزن عمومی برای همه قابل مشاهده‌اند؛ فقط فایل‌هایی را منتشر کنید که اجازه انتشارشان را دارید.
- برای پیش‌نمایش محلی از داخل پوشه دستور `python -m http.server 8000` را اجرا کنید و به `http://localhost:8000` بروید. بازکردن مستقیم HTML ممکن است بارگذاری JSON را مسدود کند.
- رمزهای عبور یا داده‌های شخصی را هرگز در مخزن عمومی قرار ندهید.
